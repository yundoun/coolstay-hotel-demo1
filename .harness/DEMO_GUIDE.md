# 🎬 꿀스테이 파트너 호텔 — 영업 시연 가이드

**데모 URL**: http://localhost:3100
**예상 시연 시간**: 2분 30초 ~ 3분
**영업 메시지 한줄**: *"꿀스테이에 입점해도 당신의 호텔 브랜드 톤은 훼손되지 않습니다."*

---

## 🎯 시연 시나리오 — Happy Path (3분)

### **[0:00~0:30] 오프닝 — 홈 랜딩**
**말할 포인트**:
- *"저희 꿀스테이는 다양한 숙박 업태를 중개하지만, 호텔 파트너는 별도의 프레젠테이션이 필요하다고 판단했습니다."*
- *"신라호텔·조선팰리스 같은 럭셔리 호텔의 에디토리얼 톤을 참고했습니다."*

**시연 동작**:
1. http://localhost:3100 접속
2. 히어로 이미지 전체화면 → *"머무는 모든 순간이 기억이 되도록"* 카피 강조
3. 하단 예약바 주목 → *"예약 위젯이 히어로와 겹쳐 바로 시작할 수 있습니다."*
4. 아래로 스크롤 → 인트로 섹션 + 6개 추천 호텔 카드

**주목시킬 UI 디테일**:
- 상단 GNB에 꿀스테이 로고만 노출 (브랜드 존재감 최소화)
- 이미지 비중 70%, 여백 충분
- 호텔 카드에 **가격이 없음** → 매거진처럼 브라우징

---

### **[0:30~1:00] "모든 호텔 30개 보기" 클릭 → `/hotels`**
**말할 포인트**:
- *"현재 제휴 호텔은 30개. 더 늘어나도 지역 필터 하나로 충분히 탐색됩니다."*

**시연 동작**:
1. 홈 맨 아래 `모든 호텔 30개 보기 →` 버튼 클릭
2. 상단 필터 바 주목:
   - 칩 하나씩 카운트 배지 노출 (`전체 30`, `수도권 10`, `제주 5`...)
   - 오른쪽 `30 / 30 개 호텔` + Sort 드롭다운
3. **"제주"** 필터 클릭 → `5 / 30 개 호텔`로 즉시 변경 확인
4. 다시 **"전체"** 클릭

**주목시킬 UI 디테일**:
- 지역별 카운트 배지 — *"제휴점 수가 그대로 보입니다"*
- 호텔 카드 3열, 여백 넉넉 → *"양이 많아도 쫓기는 느낌이 없습니다"*

---

### **[1:00~1:30] 호텔 상세 진입 → `/hotels/sowol-seoul`**
**말할 포인트**:
- *"호텔별 상세 페이지입니다. 호텔의 서사를 먼저 보여주고, 시설, 객실, 공간의 기록 순으로 노출됩니다."*

**시연 동작**:
1. **소월 서울** 카드 클릭
2. 풀스크린 히어로 → 호텔명 + `SEOUL · 5-STAR HOTEL` 라벨
3. 아래로 천천히 스크롤:
   - 컨셉 섹션 (좌측 라벨 + 우측 내러티브)
   - 시설 & 서비스 (아이콘 6개)
   - 객실 3개 (DELUXE / PREMIER / SIGNATURE) — **가격은 안 보임**
   - 갤러리 "공간의 기록" 비대칭 7장 그리드
   - 주소·체크인·문의 정보 블록
4. 하단 CTA `예약하기 →` 클릭

**주목시킬 UI 디테일**:
- 가격을 끝까지 감춤 → *"마케팅 사이트처럼 느껴지고, 가격 비교 사이트 느낌이 안 납니다"*
- 갤러리의 **비대칭 그리드** → *"매거진 레이아웃으로 브랜드 위상을 유지합니다"*

---

### **[1:30~2:00] 예약 Step 1 → Step 2**
**말할 포인트**:
- *"예약은 총 4단계입니다. 일정 선택 → 호텔/객실 → 투숙객 정보 → 확인."*

**시연 동작**:
1. **Step 1 (일정 선택)**: 체크인/체크아웃 기본값 확인 + 성인 2명 → `다음 →`
2. **Step 2 (객실 선택)**: 소월 서울이 자동 선택된 상태로 진입
3. 상단 필터는 **`/hotels`와 동일한 UX** 가리키기
4. 객실 3개 리스트 → 여기서 **처음으로 가격이 공개됨**
   - DELUXE ₩380,000 / PREMIER ₩540,000 / SIGNATURE ₩920,000
5. `디럭스 룸`의 `선택` 버튼 클릭 → 노란 좌측 테두리 액센트 + "선택됨" 표시
6. `다음 →`

**주목시킬 UI 디테일**:
- *"2박 합계"* 실시간 계산 표시
- 선택된 객실의 **좌측 노란 바 2px** (절제된 시그널)

---

### **[2:00~2:30] Step 3 (투숙객 정보) → Step 4 (확인)**
**시연 동작**:
1. **Step 3**: 간단히 입력
   - 이름: `김꿀벌`
   - 휴대폰: `010-1234-5678`
   - 이메일: `honeybee@coolstay.kr`
   - 요청사항: `늦은 체크인 예정입니다.` (선택)

2. `다음 →`
3. **Step 4**: 전체 리뷰 카드 (호텔/일정/투숙객/결제 요약)
   - 합계 ₩760,000 Serif 32px로 임팩트 있게
4. `예약 내용을 확인했으며...` 체크
5. `예약 확정` 클릭

## ⚠️ 시연 중 예상 질문 & 답변

**Q. 제휴점이 100개 넘으면 이 필터로 충분한가요?**
- A: 지역 필터 + 정렬(가나다/등급)로 대부분 해결됩니다. 필요 시 등급/시설 필터를 추가할 수 있지만, 호텔 수가 많아도 브랜드 톤을 유지하려면 **필터를 단순하게** 가져가는 게 럭셔리 UX 원칙입니다.

**Q. 실제 결제는 어떻게 되나요?**
- A: 이 데모는 mock입니다. 실제 구현 시에는 PG 연동(토스/나이스/KCP) 추가하거나, **"호텔에서 체크인 시 결제" 방식**도 지원 가능합니다 (현재 Step 4에 "호텔 결제 시 안내" 문구로 암시).

**Q. 호텔별 커스텀 디자인은 가능한가요?**
- A: 가능합니다. 현재 디자인 토큰 시스템 (컬러/타이포/스페이싱)이 CSS 변수로 분리되어 있어, 호텔별 테마 변수 오버라이드가 자연스럽습니다.

**Q. 모바일 대응은 되나요?**
- A: 데스크톱 우선으로 최적화됐지만, 반응형 그리드로 태블릿/모바일에서도 깨지지 않습니다. 본격적인 모바일 UX는 실제 구현 단계에서 보강 계획.

**Q. 다이닝 / 멤버십은 왜 없나요?**
- A: 데모 범위를 호텔 예약의 핵심 플로우로 집중했습니다. 실제 구현 시 확장 가능 (꿀스테이 기존 플랫폼에 해당 기능 이미 있음).
